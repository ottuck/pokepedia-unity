속성 기반 울음소리 (새로 합성)

원본 음원을 쓰지 않고 브라우저에서 즉석 합성합니다. 규칙은 "주 속성이 소리의 성격, 보조 속성이 덧칠, 종족별 음높이·길이는 데이터"입니다. 같은 규칙을 Unity에서 그대로 생성하거나 WAV로 구워 쓸 수 있습니다. 버튼을 누를 때마다 같은 소리가 납니다(시드 고정).
v3: 전기·물·불꽃·풀·비행은 노이즈 가공(실제 소리 흉내) 방식입니다 — 전기 = 충전 → 낙뢰 크랙 → 전류 아크 → 천둥 꼬리(라이트닝 스킬), 물 = 물살 + 거품 + 마법 반짝임, 불꽃 = 화악 발사 + 화염 + 착탄 폭발(파이어볼), 풀 = 바람 + 잎사귀 + 덩굴 채찍, 비행 = 날갯짓 3번 + 돌풍(휘파람 제거).

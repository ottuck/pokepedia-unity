스프라이트 스타일 비교

PokeAPI 스프라이트(1~151번)를 같은 배경에 올려 비교한 페이지입니다. 이미지는 저장소에서 직접 불러오므로 인터넷 연결이 필요합니다. 크기가 서로 달라 정수 배율(Point 필터)로 비슷한 크기가 되도록 확대했고, 원본 해상도는 각 카드의 표시를 참고하세요.

1. 배틀 화면 목업: 피카츄(뒷모습) vs 거북왕(앞모습)

배틀 화면 배치(NPC 오른쪽 위, 플레이어 왼쪽 아래)에 올린 모습입니다. 실제 UI는 포함하지 않았습니다.

2. 로스터 6마리: 앞/뒤 비교

피카츄, 거북왕, 리자몽, 이상해꽃, 팬텀, 뮤츠. 각 칸의 왼쪽이 앞모습, 오른쪽이 뒷모습입니다.

3. 색이 다른 포켓몬(shiny) 확인: 크리스탈 / 기본

1세대에는 shiny가 없어서 2세대 이후 세트에서만 제공됩니다. 왼쪽부터 일반 앞, shiny 앞, 일반 뒤, shiny 뒤.

4. 애니메이션 스프라이트(GIF) 샘플

크리스탈 animated(앞모습만 조사)와 블랙·화이트 animated(앞/뒤). Unity는 GIF를 직접 임포트하지 못하므로 변환이 필요합니다.

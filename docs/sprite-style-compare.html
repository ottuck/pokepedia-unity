Sprite Style Comparison

Compares PokeAPI sprites (#1–151) on the same background. Images are loaded directly from the repository, so an internet connection is required. Sizes differ, so they are enlarged by integer scaling (Point filter) to roughly the same size; see each card for the original resolution.

1. Battle screen mockup: Pikachu (back) vs Blastoise (front)

Placed in the battle screen layout (NPC top right, player bottom left). The actual UI is not included.

2. Six roster Pokémon: front/back

Pikachu, Blastoise, Charizard, Venusaur, Gengar, Mewtwo. In each cell, the left is the front view and the right is the back view.

3. Shiny check: Crystal / default

Gen 1 has no shinies, so they exist only in Gen 2 and later sets. From the left: normal front, shiny front, normal back, shiny back.

4. Animated sprite (GIF) samples

Crystal animated (front only checked) and Black/White animated (front/back). Unity cannot import GIFs directly, so conversion is required.
